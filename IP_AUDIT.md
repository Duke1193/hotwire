# IP / provenance audit — GETAWAY

Last reviewed: 2026-09-06 · Reviewed at commit: see `git log` for this file.

This document records where everything in this repository came from, so the
project's independence can be checked rather than assumed. It is an
engineering record, **not legal advice, and not a clearance certificate**. Code
and asset analysis cannot establish that a product is free of third-party
rights; see *Open questions* at the end.

## 1. What this game is

GETAWAY is an original top-down arcade driving game: you walk, take a car,
drive it badly, attract police attention, and try to lose them. It draws on the
broad late-90s top-down driving genre in the same way any racing game draws on
racing games.

It is **not** a port, remake, clone, remaster, total conversion, "web edition"
or asset package of any existing title, and is not presented as one anywhere in
the product, its metadata or its marketing copy.

`GTA` · `GTA2` · `Grand Theft Auto` · `Rockstar` · `Rockstar Games` ·
`Take-Two` · `Vice City` · `Liberty City` · `San Andreas`

searched for; exclude `IP_AUDIT.md` to see the product on its own. No third-party game is named anywhere in the product, its

Also confirmed absent: no decompiled or reverse-engineered source, no game data

audio, no third-party fonts, no scraped or fan-uploaded material of any kind.
The repository contains only files authored for this project plus npm
dependencies.

## 4. Visual audit

Every sprite is a runtime drawing: `car-coupe`, `car-sedan`, `car-hatch`,
`car-wagon`, `car-van`, `car-slate`, `car-patrol`, `ped` and `ped-1..5`,
`tree`, `planter`, `lamp`, `marker`, `chev`, `puff`, `spark`, `skid`,
`stick-base`, `stick-knob`, `shadow-soft`, `px`.

Checked specifically for, and confirmed absent:

- **No recreated map or city layout.** The grid comes from our own road/block
  parameters and a seeded generator.
- **No copied vehicle or character art.** Cars are rounded rectangles with a
  cabin, glass and lights; pedestrians are a torso capsule plus a head.
- **No wanted stars.** Police attention is a single horizontal HEAT meter. The
  pursuit-level indicator was changed during this pass from three dots to three
  short upright bars, so it reads as part of the meter and not as a star row.
- **No borrowed HUD or menu composition.** The HUD is a left-aligned meter with
  a score line, a bottom-centre prompt, a corner speed readout and a DOM chip
  row. The nickname screen is a title, one field and one button.
- **No gang, faction or colour-coded team systems**, no map icons, no weapons,
  no weapon graphics, no crime-tier iconography.
- **No third-party logos or wordmarks.** The only wordmark is "GETAWAY", set in
  the system monospace font.
- **Police livery** is a generic white vehicle with a dark shoulder band and a
  blue/red light bar — the common visual shorthand for an emergency vehicle,
  not any specific department's or game's markings.
- **Mobile controls** were designed for this project: a floating thumb stick
  and labelled rectangular pill buttons reading GO / BRAKE / DRIFT / EXIT /
  ENTER, in the HUD's own colours. Deliberately not a D-pad and not a ring of
  circular icons.

## 5. Audio audit

Every sound is synthesised at runtime from oscillators, filtered noise and
envelopes we wrote. **No sound file exists in this repository**, nothing is
sampled, and no cue reproduces the tone, cadence or composition of another
game's audio.

| Sound | Method |
| --- | --- |
| City ambience | Looping brown noise through a low-pass, plus occasional distant two-tone horns |
| Engine | Sawtooth + square oscillators through a resonant low-pass; pitch and cutoff track speed and throttle |
| Tyre scrub / drift | Looping noise through a high-Q band-pass, gain driven by lateral slip |
| Braking | Short band-passed noise burst |
| Collisions | Noise burst, band-pass centre and length switched between light and heavy hits; heavy adds a low sawtooth thud |
| Horn | Two square oscillators a fourth apart |
| Pedestrian reactions | Short triangle blip, randomised pitch |
| Police siren | Square oscillator with a triangle-LFO pitch sweep through a low-pass; rate, gain and cutoff scale with pursuit proximity |
| UI cues (mission accepted, checkpoint, mission complete, mission failed, heat increase, pursuit lost, player joined, Heat Run start, Heat Run winner) | Short original note motifs, plain intervals, defined as data in `src/systems/Audio.ts` |

No external audio was sourced, so no third-party licence applies. If any sample
is ever added, this table must gain filename, source, author, licence, source
URL and modifications, per project policy — and anything of uncertain
provenance must be replaced with a procedural alternative.

## 7. Naming

**"GETAWAY" is a working title for this technical pass.** It has not been
searched or cleared, and this document makes no claim that it is available.
The word is generic and is used by other products in other categories.

> Final product name requires separate trademark/name clearance before
> commercial launch.

Nothing in the codebase depends on the name: it appears in the page title, the
Open Graph tags, the nickname screen, the in-game title card and this README
family of documents. A rename is a copy change, not an engineering project.

## 8. Open questions before commercial launch

These cannot be resolved by reading code and are listed so they are not
forgotten:

1. **Trademark clearance** for the final product name in the intended markets.
2. **Genre/trade-dress review** by a qualified lawyer if the game is
   commercialised — this audit establishes independent authorship, which is a
   different question from whether any third party might still object.
3. **Marketing copy discipline.** Store listings, ads and social posts must not
   position the game by reference to another title. Comparative phrasing such
   as "like <title>" in paid copy is a marketing decision with legal exposure
   and is outside this repository's control.
4. **Third-party asset policy.** If art, audio or fonts are ever added, each
   needs a row in §3 with full provenance before it ships.
5. **Privacy.** Analytics collect an anonymous local UUID, room code and
   gameplay counters. Nicknames are never sent as analytics properties. A
   privacy notice will be needed before launch in most jurisdictions.
